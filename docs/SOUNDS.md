# 사운드 넣는 법

> 이 문서는 `client/src/audio/soundList.js`에서 만든다 (`npm run sounds:doc -w client`). 직접 고치지 말고 목록을 고친다.

소리 파일 **19개**. 만든 파일을 아래 이름 그대로 `client/src/assets/sounds/`에 넣으면 게임이 알아서 쓴다.
빠진 소리는 조용히 건너뛰므로 만드는 대로 하나씩 넣어도 된다.

## 1. 넣는 곳과 이름

```
client/src/assets/sounds/
├─ bgm/              배경 음악 2개: lobby.mp3, game.mp3
├─ attack/           유닛별 공격 14개: peasant.mp3, pikeman.mp3, longbowman.mp3 …
├─ construction.mp3  짓는 중 (모든 건물, 반복)
├─ complete.mp3      건설 완료 (모든 건물)
└─ alarm.mp3         알람 (모든 상황)
```

- 이름은 아래 표의 **파일** 그대로: 영어 소문자·숫자·`_`만 (한글·빈칸·대문자 X). 예: `attack/pikeman.mp3`, `alarm.mp3`
- 폴더(`bgm/`, `attack/`)는 만들어 두었다. 폴더 안의 `.gitkeep`은 지우지 않아도 된다.
- 짓는 중·건설 완료·알람은 **파일 하나를 모든 건물·상황이 같이 쓴다.**
- 공격이 없는 유닛(수송선·매 정찰병)은 공격 소리가 없다. 공격하는 건물은 유닛 소리를 빌려 쓴다: 감시탑 → `attack/longbowman.mp3` (장궁병)
- (선택) 같은 소리를 여러 개 넣으면 날 때마다 무작위로 하나가 난다: `attack/pikeman_1.mp3`, `attack/pikeman_2.mp3`

## 2. 파일 만들 때

- 형식: **.mp3** · 44.1kHz (모든 브라우저·아이폰에서 난다. .ogg/.wav/.m4a도 읽지만 아이폰에서 안 날 수 있다)
- 배경 음악: 스테레오 · 128–192kbps · 끝과 처음이 자연스럽게 이어지게 (끝나면 처음부터 다시 튼다) · 한 곡 5MB 이하
- 알람: 모노 · 0.5–2초 · 앞 무음 없이 바로 시작 · 짧고 또렷하게 (여러 상황이 같이 쓰니 특정 대사보다 경고음·뿔나팔·종이 어울린다)
- 공격·건물 소리: 모노 · 앞 무음 없이 바로 시작 · 공격 0.2–1초 · 짓는 중 2–4초 (끝과 처음이 이어지게, 되풀이된다) · 건설 완료 1–3초
- 소리끼리 크기를 비슷하게 맞춘다 (어떤 것만 튀지 않게). 게임 안 **소리** 버튼에서 전체·배경 음악·알람·공격·건물 소리 크기를 따로 줄일 수 있다.
- 효과음은 300KB, 음악은 8MB를 넘지 않게 (넘으면 점검이 알려 준다).

## 3. 넣은 뒤

1. 확인: 빠진 소리·이름이 틀린 파일·너무 큰 파일을 알려 준다.
   ```bash
   npm run sounds:check -w client
   ```
2. 개발 서버(`npm run dev`)를 켜 두었으면 브라우저를 **새로 고침**만 하면 들린다.
3. 사이트에 올리기: GitHub에 올라가면 Netlify가 다시 빌드한다. 둘 중 편한 쪽으로.
   - GitHub 웹: 저장소에서 `client/src/assets/sounds/` 폴더로 들어가 **Add file → Upload files**로 올린다.
     공격 소리는 `attack/`, 음악은 `bgm/` 폴더 안에서 올린다.
   - 터미널:
     ```bash
     git add client/src/assets/sounds
     ```
     ```bash
     git commit -m "사운드 추가"
     ```
     ```bash
     git push
     ```
4. 소리는 브라우저 정책 때문에 화면을 한 번 누른 뒤부터 난다.

## 4. 전체 목록

### 배경 음악

| 파일 | 언제 | 어떤 소리 (예시) | 길이 |
|---|---|---|---|
| `bgm/lobby.mp3` | 첫 화면 · 로비 · 대기실 | 중세 판타지풍. 차분하고 오래 들어도 지치지 않게 | 1–3분 · 반복 |
| `bgm/game.mp3` | 경기 중 (튜토리얼·리플레이·결과 화면 포함) | 잔잔하지만 살짝 긴장감 있는 중세풍 | 2–4분 · 반복 |

### 건물

| 파일 | 언제 | 어떤 소리 (예시) | 길이 |
|---|---|---|---|
| `construction.mp3` | 농노가 건물을 짓는 동안 그 자리에서 되풀이 (화면 속 공사 터 가까운 2곳까지) | 망치질·톱질 같은 공사 소리 | 2–4초 · 반복 |
| `complete.mp3` | 우리 건물이 다 지어진 순간 (화면 밖이어도 들린다) | 완공을 알리는 밝은 종이나 짧은 팡파르 | 1–3초 |

### 알람

| 파일 | 언제 | 어떤 소리 (예시) | 길이 |
|---|---|---|---|
| `alarm.mp3` | 알려야 할 일이 생겼을 때 (공격받음·자원 부족·지을 수 없음 등 모든 경우) | 짧고 또렷한 경고음 · 뿔나팔 · 종 | 0.5–2초 |

### 알람이 울리는 경우

모두 `alarm.mp3` 하나가 난다. 무슨 일인지는 화면 글로 알린다. 알람끼리 겹치면 급한 쪽이 먼저다.

| 경우 | 같은 경우 다시 울리기까지 | 급한 정도 |
|---|---|---|
| 화면 밖의 우리 병력이 공격받을 때 | 12초 | 높음 |
| 화면 밖의 우리 건물이 공격받을 때 | 12초 | 높음 |
| 화면 밖의 팀원이 공격받을 때 (팀전) | 20초 | 높음 |
| 금이 모자랄 때 | 1.5초 | 보통 |
| 목재가 모자랄 때 | 1.5초 | 보통 |
| 마나가 모자랄 때 | 1.5초 | 보통 |
| 인구가 가득 차 생산이 멈췄을 때 | 10초 | 보통 |
| 그 자리에 지을 수 없을 때 | 1초 | 보통 |

| 우리가 캐던 금광이 바닥났을 때 | 5초 | 높음 |

| 팀원이 쓰러졌을 때 (팀전) | 바로 | 가장 높음 |
